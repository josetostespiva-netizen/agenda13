O aplicativo abre no Windows

Este projeto é um aplicativo .NET MAUI nativo, escrito em C# e XAML. A interface funciona em uma janela própria do Windows. O Brave está exibindo este guia local; esta página não é uma versão web do aplicativo.

Para abrir novamente, no VS Code escolha Terminal → Executar Tarefa → Agenda 13: executar no Windows.

Explore as três telas

  1. App Hotel: escolha os hóspedes, a suíte e as datas.
  2. Resumo: clique em “Calcular minha estadia” para conferir o valor. “Editar minha estadia” preserva suas escolhas.
  3. Sobre: na barra superior do App Hotel, abra as informações do projeto e do desenvolvedor.

As tarifas são demonstrativas. Nenhuma reserva ou cobrança é realizada.

Código e referências

O projeto se chama agenda13 e está organizado em Views, Models e Tests. As instruções completas estão no arquivo README.md aberto no VS Code.
